# SimRyoko 产品描述模板

## 单国eSIM套餐模板

### 标题格式
`{国家名} eSIM流量卡 | {流量}{天数}天`

### 短描述（用于商品卡片）
`{国家名}旅游上网必备，{流量}高速流量，有效期{天数}天。即买即用，无需换卡。`

### 完整描述模板
```
🌐 {国家名} eSIM数据套餐

📦 套餐内容：
• 数据流量：{流量}
• 有效期：{天数}天（从激活日起算）
• 网络制式：4G/5G
• 覆盖范围：{国家名}全境

✅ 产品特点：
• 即买即用：购买后即刻收到QR码
• 无需换卡：保留原有SIM卡和号码
• 高速网络：接入当地优质运营商
• 即时激活：扫码安装，秒速联网

📱 兼容设备：
• iPhone XS及以上所有机型
• Samsung Galaxy S20及以上
• Google Pixel 3及以上
• 其他支持eSIM的安卓设备

📋 使用步骤：
1. 购买后通过邮件/消息收到QR码
2. 前往手机「设置」→「蜂窝网络」→「添加eSIM」
3. 扫描QR码完成安装
4. 到达{国家名}后开启数据漫游
5. 畅享高速网络！

⚠️ 注意事项：
• 请确认您的设备支持eSIM且已解锁
• 本套餐仅含数据流量，不含语音通话和短信
• 流量用完后可购买续费包
• 建议出发前安装eSIM，到达目的地后激活

💬 客服支持：7×24小时中英双语客服
```

## 多国/区域eSIM套餐模板

### 标题格式
`{区域名} eSIM流量卡 | {国家数}国通用 {流量}{天数}天`

### 短描述
`覆盖{区域名}{国家数}个国家和地区，一张eSIM走遍{区域名}。{流量}高速流量，{天数}天有效。`

### 完整描述模板
```
🌍 {区域名}多国eSIM数据套餐

📦 套餐内容：
• 数据流量：{流量}（多国共享）
• 有效期：{天数}天
• 覆盖国家：{国家数}国
• 网络制式：4G/5G

🗺️ 覆盖国家列表：
{国家列表}

✅ 特别适合：
• 多国连续旅行（如欧洲游）
• 商务出差覆盖多个目的地
• 无需每到一国更换SIM卡
```
