Developer API

REST API — integrate in minutes

Full REST API with JSON responses. Authentication via API key. Rate-limit: 100 requests/minute.

ENDPOINTS

GET /api/v1/products List all eSIM plans
GET /api/v1/products?country=JP Filter by country
POST /api/v1/orders Place an eSIM order
GET /api/v1/orders/{id} Get order + eSIM QR
GET /api/v1/balance Check account balance

EXAMPLE REQUEST

curl -X POST https://simryoko.com/api/v1/orders \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [{"id": 1042, "quantity": 1}],
    "email": "customer@example.com"
  }'

EXAMPLE RESPONSE

{
  "success": true,
  "order": {
    "id": "ORD-20260224-001",
    "status": "fulfilled",
    "esim": {
      "qr_code_url": "https://...",
      "activation_code": "LPA:1$...",
      "iccid": "89883030..."
    }
  }
}
