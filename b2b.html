FAQ

B2B Partner FAQ

How quickly can I start selling after applying? ＋
Most applications are approved within 24 hours. Once approved, you'll receive your account credentials, and you can start placing orders immediately via our dashboard. API keys are also issued instantly upon approval.
What payment methods do partners use to top up? ＋
We currently accept USDT (TRC-20) for partner account top-ups. No bank wire, no credit card fees. Enterprise partners on Net-30 terms can be invoiced via other arrangements — contact us to discuss.
Can I white-label or brand the eSIM QR codes? ＋
White-label options are available on our Enterprise tier ($5,000+/month). This includes branded QR code delivery emails, custom domain setup, and optional co-branding on the activation page. Contact our sales team via email for details.
Is there a minimum monthly purchase requirement? ＋
No minimum order, ever. You can buy a single eSIM or thousands. There's no monthly commitment on Starter or Growth tiers. Your margin tier upgrades automatically based on your rolling monthly volume.
What happens if an eSIM doesn't work for my customer? ＋
We offer a 7-day refund or replacement policy for non-activated eSIMs. For activated eSIMs with connectivity issues, our support team investigates within 2 hours and either resolves the issue or provides a replacement. Partner accounts get priority support response times.

Developer API

REST API — integrate in minutes

Full REST API with JSON responses. Authentication via API key. Rate-limit: 100 requests/minute.

ENDPOINTS

GET /api/v1/products List all eSIM plans
GET /api/v1/products?country=JP Filter by country
POST /api/v1/orders Place an eSIM order
GET /api/v1/orders/{id} Get order + eSIM QR
GET /api/v1/balance Check account balance

EXAMPLE REQUEST

curl -X POST https://simryoko.com/api/v1/orders \
  -H "X-Api-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [{"id": 1042, "quantity": 1}],
    "email": "customer@example.com"
  }'

EXAMPLE RESPONSE

{
  "success": true,
  "order": {
    "id": "ORD-20260224-001",
    "status": "fulfilled",
    "esim": {
      "qr_code_url": "https://...",
      "activation_code": "LPA:1$...",
      "iccid": "89883030..."
    }
  }
}
