### 9.1 接口概览

| 接口 | 方法 | 路径 | 用途 |
|------|------|------|------|
| 获取产品列表 | GET | /api/products | 首页/列表页 |
| 获取产品详情 | GET | /api/products/{id} | 产品详情页 |
| 按国家筛选 | GET | /api/products?country={code} | 国家页 |
| 实时库存查询 | GET | /api/inventory/{id} | 产品页/结账 |
| 创建订单 | POST | /api/orders | 结账提交 |
| 支付处理 | POST | /api/payment | 支付流程 |
| 查询订单 | GET | /api/orders/{id} | 订单详情 |

### 9.2 接口详细规格

#### 获取产品列表

**请求**:
```
GET /api/products?page=1&limit=20&country=jp&type=local&sort=price_asc
```

**参数**:
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码，默认1 |
| limit | number | 否 | 每页数量，默认20 |
| country | string | 否 | 国家代码，如jp |
| type | string | 否 | 类型: local/regional/global |
| sort | string | 否 | 排序: price_asc/price_desc/popular |
| data_size | string | 否 | 流量筛选: 1gb/3gb/5gb/unlimited |
| valid_days | number | 否 | 有效期筛选: 7/15/30 |

**响应**:

```json
{
```

### 9.3 错误处理规范

| 状态码 | 场景 | 前端处理 |
|--------|------|----------|
| 200 | 成功 | 正常显示 |
| 400 | 参数错误 | 显示表单错误 |
| 401 | 未登录 | 跳转登录页 |
| 404 | 产品不存在 | 显示404页面 |
| 422 | 库存不足 | 显示缺货提示 |
| 500 | 服务器错误 | 显示错误提示+重试 |
| 503 | 服务维护 | 显示维护页面 |

**错误响应格式**:
```json
{
  "success": false,
  "error": {
    "code": "INSUFFICIENT_STOCK",
    "message": "该产品库存不足",
    "details": {
      "productId": 141,
      "requested": 1,
      "available": 0
    }
  }
}
```
