## 核心功能PRD

### 功能1: 实时库存查询
**需求**: 当前100%产品库存显示999，需显示真实库存

**API设计**:
```
GET /api/inventory/{productId}
Response: { productId, stock, available, lastUpdated }
```

**实现要点**:
- 缓存TTL: 5分钟
- 降级策略: API失败显示"库存充足"
- 限流: 100次/分钟

**验收标准**:
- [ ] 响应时间 < 500ms
- [ ] 超卖事件 = 0
- [ ] 系统可用性 > 99.9%

### 功能2: 智能推荐系统
**算法逻辑**:
1. 目的地匹配 (精确 > 区域 > 全球)
2. 销量排序 (热销优先)
3. 利润排序 (669款高利润产品优先)
4. 价格段匹配

**推荐场景**:
- 搜索国家 → 返回Top 3
- 购物车 → 推荐搭配
- 结账完成 → 推荐相关目的地

### 功能3: 销量统计系统
**数据库表**:
```sql
CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  product_id INTEGER,
  quantity INTEGER,
  amount DECIMAL(10,2),
  customer_email VARCHAR(255),
  created_at TIMESTAMP,
  status VARCHAR(20)
);

CREATE TABLE product_stats (
  product_id INTEGER PRIMARY KEY,
  total_sold INTEGER DEFAULT 0,
  total_revenue DECIMAL(10,2) DEFAULT 0,
  last_updated TIMESTAMP
);
```
