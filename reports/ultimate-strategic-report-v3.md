### 2.2 核心功能PRD

#### 功能1: 实时库存查询系统

**需求背景**: 当前100%产品库存显示999（默认值），存在超卖风险

**用户故事**:
- 作为客户，在结账时能看到真实库存，避免付款后无货
- 作为运营，能及时发现库存不足产品并下架

**功能描述**:
- 产品列表页: 显示"库存充足"（不显示具体数字）
- 产品详情页: 显示"库存充足/紧张/缺货"状态
- 结账页: 实时查询API，显示精确库存
- 支付前: 二次确认库存，防止超卖

**技术方案**:
- API: GET /api/inventory/{productId}
- 缓存: 5分钟TTL
- 降级: API失败时显示"库存充足"
- 限流: 每分钟100次

**验收标准**:
- [ ] 库存查询响应<500ms
- [ ] 超卖事件为0
- [ ] 系统可用性>99.9%

#### 功能2: 智能产品推荐

**推荐算法**:
1. 目的地匹配（精确>区域>全球）
2. 销量排序（热销优先）
3. 利润排序（高利润优先）
4. 价格段匹配（根据用户行为）

**推荐场景**:
- 搜索国家 → 推荐该国家Top 3产品
- 浏览历史 → 推荐相似产品
- 购物车 → 推荐搭配产品
- 结账完成 → 推荐目的地相关产品

#### 功能3: 销量统计与热销榜

**数据表设计**:
```sql
orders (
  id INT PRIMARY KEY,
  product_id INT,
  quantity INT,
  amount DECIMAL(10,2),
  customer_email VARCHAR(255),
  created_at TIMESTAMP,
  status ENUM('pending', 'paid', 'refunded')
)

product_stats (
  product_id INT PRIMARY KEY,
  total_sold INT DEFAULT 0,
  total_revenue DECIMAL(10,2) DEFAULT 0,
  last_updated TIMESTAMP
)
```

### 4.2 常见问题FAQ（标准答案）

**Q1: 我的手机支持eSIM吗？**
> A: iPhone XS及更新机型支持（国行需确认）。Android支持Google Pixel、Samsung Galaxy S20+等。您可以在"设置>通用>关于本机"查看是否有"IMEI2"或"eSIM"选项。不确定的话，可以提供手机型号我帮您查。

**Q2: 我不会安装eSIM**
> A: 我们提供全程图文教程，iPhone和Android都有详细步骤。购买后您会收到邮件，里面有教程链接。如果还是不会，可以预约我们的视频指导服务，客服手把手教您。

**Q3: 买了之后多久能收到？**
> A: 支付成功后立即显示二维码，同时发送到您的邮箱。无需等待，即买即用。建议出发前购买并安装好，落地就能上网。

**Q4: 流量用完了怎么办？**
> A: 大部分套餐支持充值续费，在您的账户页面点击"充值"即可。如果该套餐不支持充值，可以购买新套餐，旧套餐剩余流量仍可使用到有效期结束。

**Q5: 可以退款吗？**
> A: 支持7天无理由退款。如果eSIM尚未使用（未扫描二维码），全额退款。如果已使用但遇到问题，我们会根据情况部分退款或提供补偿。

**Q6: 为什么比淘宝贵？**
> A: 淘宝很多是共享账号或违规操作，随时可能被封，没有售后保障。我们是正规授权经销商，稳定可靠，有24/7客服支持，7天退款保证。

**Q7: 能打电话吗？**
> A: 大部分套餐是纯数据，不能打电话。但我们的Discover+全球套餐支持语音短信，包含当地电话号码，可以接听拨打电话、收发短信。适合商务人士。

**Q8: 信号好吗？**
> A: 我们与当地主流运营商合作，使用4G/LTE网络，信号覆盖与本地SIM卡相同。在城市和旅游区信号良好，偏远地区可能较弱。
