# 每日站会议程模板

**用途**: 15分钟快速同步  
**参与**: UI + 前端 + 后端 + PM  
**时间**: 每天 10:00

---

## 会议结构 (15分钟)

```
时间分配:
├── 每人发言: 2分钟 × 4人 = 8分钟
├── 问题讨论: 5分钟
└── 总结确认: 2分钟
```

---

## 发言模板

### 每个人按此格式:

```
1. 昨天完成:
   - [具体任务1]
   - [具体任务2]

2. 今天计划:
   - [具体任务1]
   - [具体任务2]

3. 阻塞/需要帮助:
   - [问题描述] → [需要的帮助]
   - 或: "无阻塞"
```

---

## 会议记录模板

```
日期: 2026-03-14
时间: 10:00-10:15
参与: UI/前端/后端/PM

## 昨日完成
- UI: 首页Desktop设计 ✅
- 前端: 项目初始化 ✅
- 后端: 数据清理 ✅

## 今日计划
- UI: 首页Mobile + 国家页设计
- 前端: ProductCard + Hero组件
- 后端: 产品列表API

## 阻塞问题
1. 语音产品展示方式 → PM今日确认
2. 首页设计稿标注 → UI今日补充

## 明日重点
- 首页设计评审
- 组件开发完成
```

---

## 阻塞问题处理

### 当场能解决 (2分钟内)
```
- 直接讨论确认
- 记录决策
- 继续执行
```

### 需要后续跟进
```
- 记录问题
- 指定负责人
- 设定解决时间
- 明日站会跟进
```

---

## 会议纪律

### Do
- [ ] 准时开始，准时结束
- [ ] 只谈具体任务和阻塞
- [ ] 有问题立即提出
- [ ] 记录行动项

### Don't
- [ ] 不要迟到
- [ ] 不要讨论细节（另约会议）
- [ ] 不要只汇报不提出阻塞
- [ ] 不要超时

## 周站会汇总

### 周五站会增加:

```
额外10分钟:
1. 本周完成回顾 (5分钟)
2. 下周计划对齐 (5分钟)
```

### 周汇总模板:

```
## Week 1 站会汇总

### 本周完成
- UI: 设计系统 + 首页设计
- 前端: 项目搭建 + 首页开发
- 后端: 数据清理 + API框架

### 下周计划
- UI: 国家/区域/全球页设计
- 前端: 国家页开发
- 后端: 筛选API完成

### 风险
- 设计进度略慢，需加班追赶

### 决策
- 优先保证首页质量上线
- 其他页面可后续迭代
```
